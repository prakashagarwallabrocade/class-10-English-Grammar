1Question

Work in pairs. Think of a puzzle whose answer you know. The clue you give must have a relative clause. For example,
A black and white bird which can swim but can’t fly. Seven letters. (Penguin)
Now, the other partner must think of a puzzle whose answer must contain one of the letters of Penguin. For example, A snow house that an Eskimo builds . Five letters. (Igloo). In this process make a crossword puzzle, always using an existing letter, e.g.

When ten words have been formed, show it to the teacher (or present before the class).

Rules used

  • Relative clauses

    A relative (adjective) clause describes the noun before it and begins with who, whom, which, that, whose (or where for a place). To combine two sentences, put the relative pronoun after the common noun.

    📖 Relative Clauses
Note: Sample answer — partners will choose their own words.
  1. Every clue must contain a relative clause (who / which / that …) that defines the word.
  2. Each new word must use a letter that is already in the puzzle, so the words cross each other.

Answer: 1. PENGUIN — a black and white bird which can swim but can’t fly.
2. IGLOO — a snow house that an Eskimo builds. (crosses PENGUIN at G)
3. NURSE — a woman who looks after patients in a hospital. (shares N)
4. LION — an animal which is called the king of the jungle. (shares L of IGLOO)
5. EAGLE — a bird which has very sharp eyes. (shares E)
6. GLOBE — a round model of the earth that we keep in the classroom.
7. OWL — a bird which hunts at night.
8. UMBRELLA — a thing which we carry when it rains.
9. INK — a liquid which we use for writing.
10. NEST — a home which a bird builds with twigs.

    1. (a) If I had known it
    2. (b) Because I knew it
    3. (c) Although I knew it
    4. (d) When I know it

  2. Choose the correct sentence.

    4. (d) If I had seen him, I will tell him.

  3. In "She speaks as if she were a queen", the adverb clause is of:

    1. (a) manner
    2. (b) reason
    3. (c) time
    4. (d) condition

    2. (b) He came although he was not invited.

    4. (d) He came so that he could meet us.

    3. (c) would

    2. (b) reason
    3. (c) time
    4. (d) result

  3. Explain the difference in meaning:
